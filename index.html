stubby Helm chart repo

Mutating admission webhook that swaps pod images for ready-to-go dummy backends and frontends. This URL is the Helm chart index; install with the commands below.

Install

helm repo add stubby https://kauemendes.github.io/stubby
helm repo update
helm install stubby stubby/stubby \
  --namespace stubby-system --create-namespace

Annotate a pod

metadata:
  annotations:
    stubby.io/type: backend          # or "frontend" or "off"
    stubby.io/app-name: "Orders API"
    stubby.io/port: "8080"
